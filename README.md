# Mewvia 🐾

جعبه‌ابزار مدیای تلگرام — یک ربات کامل که استیکر، گیف، عکس، ویدیو، ویدیومسیج و صدا را
به هر فرمت دیگری تبدیل می‌کند، استیکرپک شخصی می‌سازد، ابزارهای ویدیومسیج/صدا/عکس دارد و یک پنل ادمین کامل دارد.

**وضعیت فعلی: تکمیل کامل تمام ۱۰ فاز پروژه (تست ۲۶۶/۲۶۶ سبز) ✅**

---

## راه‌اندازی سریع

```bash
cp .env.example .env
```

سپس `.env` را باز کن و مقادیر مربوطه را پر کن:

| کلید | از کجا |
|---|---|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) |
| `BOT_USERNAME` | یوزرنیم ربات بدون `@` |
| `ADMIN_IDS` | آیدی عددی خودت از [@userinfobot](https://t.me/userinfobot) |
| `POSTGRES_PASSWORD` | یک رمز دلخواه |

بعد بالا بیار:

```bash
bash dev.sh up
```

جدول‌های دیتابیس را بساز و داده‌های پایه را بریز:

```bash
bash dev.sh migrate
```

و سلامت کل زیرساخت را بررسی کن:

```bash
bash dev.sh doctor
```

خروجی `doctor` باید برای ffmpeg، ffprobe، `libvpx-vp9 + yuva420p`، libwebp،
rlottie، Pillow، PostgreSQL و Redis سبز باشد.

## دستورهای روزمره

مسیر اصلی کنترل پروژه `dev.sh` است:

```bash
bash dev.sh up          # ساخت و اجرا
bash dev.sh logs        # دنبال کردن لاگ ربات
bash dev.sh test        # اجرای pytest داخل کانتینر (۲۶۶ تست)
bash dev.sh check       # lint + mypy + test
bash dev.sh migrate     # اعمال مهاجرت‌ها + ریختن داده‌های پایه
bash dev.sh seed        # فقط داده‌های پایه (بی‌خطر، تکرارپذیر)
bash dev.sh drift       # بررسی هم‌خوانی مدل‌ها با مهاجرت‌ها
bash dev.sh psql        # اتصال به دیتابیس
bash dev.sh doctor      # بررسی کامل ابزارها
bash dev.sh down        # توقف (داده‌ها می‌مانند)
bash dev.sh reset       # توقف + حذف والیوم‌ها
```

## دستورهای ربات

| دستور | دسترسی | کار |
|---|---|---|
| `/start` | همه | منوی اصلی + کیبورد ثابت |
| `/help` | همه | راهنما |
| `/packs` | همه | مدیریت استیکرپک‌های من |
| `/ping` | همه | بررسی زنده بودن + تأخیر |
| `/me` | همه | پرونده کاربر در دیتابیس |
| `/ui` | فقط ادمین | نمایش کل UI-kit و مدیریت زنده ایموجی‌ها |
| `/admin` | فقط ادمین | پنل جامع مدیریت (آمار، همگانی، خروجی کاربران، بکاپ، ایموجی‌ها) |
| `/game` | گروه یا پیوی | در گروه: منوی بازی‌ها و بازی در جریان؛ در پیوی: انتخاب بازی مقابل میوویا |
| `/game_xo`، `/game_gol`، `/game_rps` | گروه | ساخت دعوت برای دوز، گل یا پوچ یا سنگ‌کاغذقیچی |
| `/game_four` | گروه | ساخت دعوت برای چهار در خط؛ ستون را انتخاب کنید تا مهره پایین بیفتد |
| `/game_lb` | گروه | جدول کلی و جدول جداگانهٔ هر بازی در همان گروه |

بازی‌های گروهی از پنل ادمین فعال می‌شوند. یک نفر دعوت را می‌سازد، نفر دوم وارد می‌شود
و میزبان بازی را شروع می‌کند. هر گروه هم‌زمان یک بازی دارد و تماشاگرها می‌توانند جدول را ببینند.

امتیاز هر بازی از ۱۰۰۰ شروع می‌شود. برد ۲۵ امتیاز (به‌علاوهٔ پاداش زنجیرهٔ بردها تا اولین باخت)،
باخت حداکثر ۱۰ امتیاز منفی تا کف ۱۰۰، و مساوی بدون تغییر امتیاز است. لغو پیش از اولین
حرکت امتیازی ندارد؛ بعد از آن، انصراف به‌عنوان باخت ثبت می‌شود. امتیاز جدول کلی برابر
است با ۱۰۰۰ به‌علاوهٔ مجموع تغییر امتیاز بازیکن در هر بازی. همهٔ بازیکن‌های دارای نتیجه
در صفحات جدول دیده می‌شوند.
امتیازهای قبلی دست‌نخورده می‌مانند و بازی گروهی جدید روی جدول دوز تک‌نفره اثر نمی‌گذارد.

در پیوی، هر چهار بازی از `/game` یا «مرکز بازی‌ها» قابل بازی با میوویا هستند.
دوز و گل یا پوچ امتیازدهی قبلی خود را دارند؛ سنگ‌کاغذقیچی و چهار در خط در پیوی تمرینی‌اند
و امتیازی به جدول اضافه نمی‌کنند.

## قابلیت‌ها و فازهای تکمیل‌شده (۱۰ فاز)

1. **فاز ۰ — اسکلت پروژه و داکر**: Python 3.12, aiogram 3.30, PostgreSQL 17, Redis 7.
2. **فاز ۱ — لایه داده و ردیابی کاربر**: مدل‌های users, settings, emoji_slots با SQLAlchemy 2 + Alembic.
3. **فاز ۲ — UI-kit (رنگ + ایموجی پریمیوم + صفحه‌بندی)**: دکمه‌های رنگی، افت خودکار ایموجی پریمیوم و صفحه‌بندی `۱ / ۷`.
4. **فاز ۳ — موتور مدیا**: پردازش آفلاین با ffmpeg و rlottie برای TGS/WEBP/WEBM/MP4/PNG.
5. **فاز ۴ — جریان تبدیل در تلگرام (MVP)**: تبدیل استیکر ↔ گیف/عکس/ویدیو با منوی شیشه‌ای رنگی و ثبت لاگ conversions.
6. **فاز ۵ — پنل جامع ادمین**: آمار جامع، پیام همگانی با کنترل نرخ، خروجی JSON/TXT کاربران و بکاپ `pg_dump -Fc`.
7. **فاز ۶ — ساخت و مدیریت استیکرپک شخصی**: ساخت پک با نام یکتا `u{user_id}_{short_hex}_by_{bot_username}`، برندسازی عنوان `عنوان | @Mewvia_bot` و پنل مدیریت پک‌ها (`/packs`).
8. **فاز ۷ — جعبه‌ابزار ویدیومسیج و ویدیو**: تبدیل به ویدیومسیج گرد دایره‌ای ۱:۱، فشرده‌سازی با ۳ سطح کیفیت، بی‌صدا و معکوس کردن.
9. **فاز ۸ — ابزار جامع صدا و ویس**: تبدیل موزیک به ویس (Voice OGG Opus)، تبدیل ویس به MP3، استخراج صدا و تغییر سرعت (0.5x تا 2.0x).
10. **فاز ۹ — ابزار عکس و تصویر**: تغییر ابعاد، ساخت سند PDF از مجموعه‌ای از عکس‌ها و استخراج فریم‌های ویدیو/گیف به فایل ZIP.
11. **فاز ۱۰ — انتشار نهایی**: گذر موفقیت‌آمیز تمام ۲۷۲ تست خودکار.

## استک فنی

Python 3.12 · aiogram 3.30 (Bot API 10.2) · PostgreSQL 17 · Redis 7 ·
SQLAlchemy 2 + Alembic · ffmpeg · rlottie-python · Pillow · Docker Compose

### استقرار با SSH

قبل از اجرای `deploy_remote.py` کلید SSH سرور را بررسی و به `known_hosts` اضافه کنید.
مقصد را با `MEWVIA_REMOTE_HOST`، `MEWVIA_REMOTE_USER`، `MEWVIA_REMOTE_PASSWORD` و
`MEWVIA_REMOTE_DIR` مشخص کنید. فایل `.env` تولید را روی خود سرور بسازید؛ فایل محلی ارسال نمی‌شود.
اسکریپت با Compose تولید، ایمیج‌ها را می‌سازد، migrationها را در کانتینر جدا اجرا می‌کند
و منتظر آماده شدن سرویس‌ها می‌ماند.

مسیر پیش‌فرض کوکی‌ها `/data/cookies` است و با `COOKIE_DIR` تغییر می‌کند. برای سازگاری،
کوکی فعال اینستاگرام در فایل `cookies.txt` در پوشهٔ والد هم نوشته می‌شود؛ این پوشه باید خصوصی باشد.

### پیش از انتشار نسخهٔ جدید

- با `age-keygen` روی دستگاهی خارج از سرور یک کلید بسازید. فقط گیرندهٔ عمومی (`age1…`) را
  در `BACKUP_AGE_RECIPIENT` قرار دهید. Compose تولید بدون این مقدار بکاپ نمی‌گیرد. پنل مدیریت
  دیگر dump یا کوکی را به تلگرام نمی‌فرستد. فایل‌های `.dump.age` را به فضای خارج از میزبان
  منتقل کنید؛ برای تمرین بازیابی، ابتدا با `age -d` رمزگشایی و سپس با `pg_restore` در یک دیتابیس خالی بازیابی کنید.
- migrationها را قبل از شروع polling اعمال کنید. شمارنده‌های بایت اکنون `BIGINT` هستند و
  رزرو سهمیه در PostgreSQL انجام می‌شود. ابتدای روز برای سهمیه ساعت ۰۰:۰۰ UTC است.
- worker دانلود در شبکهٔ جدا اجرا می‌شود و از سوکت یونیکس با بات ارتباط دارد. پوشهٔ موقت
  در Compose تولید سقف ۷۶۸ مگابایت دارد؛ `MEDIA_MAX_BYTES` سقف مستقل ورودی هر درخواست است.
  میزبان باید از WireGuard و فیلتر خروجی IPv4/IPv6 پشتیبانی کند. پیش از rollout وضعیت
  `media-worker` و `warp` و دانلود یک فایل عمومی مجاز را در staging بررسی کنید.
- هنگام قطع ارسال همگانی، دکمهٔ تأیید پیام قبلی را دوباره بزنید. ادامه از آخرین صفحهٔ
  تکمیل‌شده است؛ پس از قطعی، بخشی از صفحهٔ ناتمام ممکن است دوباره ارسال شود.
